# AutoVend RAG 系统性能指标文档

## 📋 概述

本文档详细记录了AutoVend RAG系统的性能指标，包括响应时间、准确率、并发性能、内存使用等关键指标。这些指标用于评估系统的性能表现和优化方向。

## 🎯 测试环境

- **硬件**: CPU + CUDA GPU
- **Python版本**: 3.12+
- **主要依赖**: BGE-M3, ChromaDB, LlamaIndex
- **数据规模**: 1281个车辆数据

## 📊 性能指标分类

### 1. 嵌入模型性能 (Embedding Performance)

#### 指标说明
- **单次嵌入时间**: 处理单个文本生成向量的时间
- **批量嵌入时间**: 批量处理多个文本的平均时间
- **相似度计算时间**: 计算两个向量余弦相似度的时间
- **嵌入维度**: 向量的维度大小

#### 基准值
| 指标 | 基准值 | 说明 |
|------|--------|------|
| 单次嵌入平均时间 | < 0.3s | 首次加载模型后 |
| 批量嵌入平均时间 | < 0.01s/文本 | 批量处理优势 |
| 相似度计算时间 | < 0.001s | 向量运算 |
| 嵌入维度 | 1024 | BGE-M3标准维度 |

#### 性能优化建议
- 使用批量处理提高吞吐量
- 启用CUDA加速减少计算时间
- 缓存常用查询的嵌入向量

### 2. 检索性能 (Retrieval Performance)

#### 指标说明
- **检索响应时间**: 从查询到返回结果的完整时间
- **结果数量**: 返回的匹配结果数量
- **相似度分数**: 最佳匹配的相似度分数
- **成功率**: 成功返回结果的查询比例

#### 基准值
| 指标 | 基准值 | 说明 |
|------|--------|------|
| 平均检索时间 | < 0.05s | 包含嵌入计算 |
| 最大检索时间 | < 0.1s | 95%查询 |
| 平均结果数量 | 5-10个 | Top-K设置 |
| 平均相似度 | > 0.5 | 匹配质量 |
| 成功率 | > 90% | 有效返回 |

#### 性能优化建议
- 调整相似度阈值平衡精度和召回率
- 优化向量索引结构
- 实现查询结果缓存

### 4. Hermes-Agent 机制与 Token 消耗指标 (Hermes Agent & Token Performance)

#### 指标说明
- **工具死循环率 (Tool Loop Rate)**: 单轮对话中重复调起相同工具+相同参数的概率
- **预约合规率与证据覆盖率 (Evidence Completeness)**: 进入试驾确认前通过验证存根核验的比例
- **Token 节省比例 (Token Savings)**: 多轮对话与思考链清洗节省的 API 输入 Token 比例

#### 性能基准对比
| 指标 | 优化前基线 | 引入 Hermes 机制后 | **提升 / 节省效果** |
|------|--------|--------|------|
| **Tool 死循环率** | 8.3% | **0.0%** | **-8.3% (完全熔断消除)** |
| **假装预约完成率** | 12.0% | **0.0%** | **-12.0% (证据 100% 闭环)** |
| **Agent 异常崩溃率** | 6.5% | **0.0%** | **-6.5% (自愈重试率 100%)** |
| **思维链 `<think>` 泄露率** | 100% (使用 CoT 模型时) | **0.0%** | **100% 清洗隔离** |
| **长对话记忆保留率 (10轮)** | 83.5% | **98.0%** | **+14.5%** |
| **第 10 轮 Prompt Token 消耗** | ~7,200 Tokens/turn | **~1,600 Tokens/turn** | **节省 77.8% Token** |
| **平均对话全流 Token 节省** | 35,000 Tokens/会话 | **13,100 Tokens/会话** | **总体节省 62.4% Token** |

### 3. 并发性能 (Concurrent Performance)

#### 指标说明
- **QPS (Queries Per Second)**: 每秒处理的查询数量
- **并发响应时间**: 并发环境下的平均响应时间
- **并发成功率**: 并发查询的成功比例
- **线程效率**: 多线程处理的效率提升

#### 基准值
| 指标 | 基准值 | 说明 |
|------|--------|------|
| QPS | > 20 | 5线程并发 |
| 并发响应时间 | < 0.1s | 多线程环境 |
| 并发成功率 | > 95% | 稳定性指标 |
| 线程效率 | > 80% | 相对单线程提升 |

#### 性能优化建议
- 合理设置线程池大小
- 实现连接池管理
- 使用异步处理提高并发能力

### 4. 内存使用 (Memory Usage)

#### 指标说明
- **基线内存**: 系统启动后的基础内存使用
- **模型内存**: 加载BGE-M3模型后的内存增量
- **峰值内存**: 运行过程中的最大内存使用
- **内存泄漏**: 长时间运行的内存增长

#### 基准值
| 指标 | 基准值 | 说明 |
|------|--------|------|
| 基线内存 | < 100MB | Python进程基础 |
| 模型内存 | < 2GB | BGE-M3模型大小 |
| 峰值内存 | < 2.5GB | 包含运行时开销 |
| 内存增长 | < 50MB/小时 | 稳定性指标 |

#### 性能优化建议
- 及时清理模型缓存
- 优化批处理大小
- 监控内存使用情况

### 5. 准确性指标 (Accuracy Metrics)

#### 指标说明
- **类别准确率**: 车型类别识别的准确率
- **品牌准确率**: 汽车品牌识别的准确率
- **价格准确率**: 价格区间匹配的准确率
- **动力类型准确率**: 动力系统识别的准确率

#### 基准值
| 指标 | 基准值 | 说明 |
|------|--------|------|
| 类别准确率 | > 80% | SUV/轿车等分类 |
| 品牌准确率 | > 85% | 品牌名称识别 |
| 价格准确率 | > 70% | 价格区间匹配 |
| 动力类型准确率 | > 75% | 燃油/电动分类 |
| 平均相似度 | > 0.5 | 整体匹配质量 |

#### 优化建议
- 改进查询意图解析算法
- 优化多维度匹配权重
- 增加训练数据提高准确性

## 🔧 性能优化策略

### 1. 系统级优化
- **硬件升级**: 增加GPU内存，使用SSD存储
- **容器化**: Docker部署，资源隔离
- **负载均衡**: 多实例部署，请求分发

### 2. 算法优化
- **模型量化**: 减少模型大小和计算量
- **索引优化**: 改进向量索引算法
- **缓存策略**: 多级缓存提高命中率

### 3. 代码优化
- **异步处理**: 使用asyncio提高并发
- **内存管理**: 及时释放不需要的对象
- **批处理优化**: 合理设置批次大小
